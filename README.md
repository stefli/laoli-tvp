## Install (Grok Bot / Cursor skills)

1. Clone this repo (or copy the folder) into your agent skills / workflows directory.
2. Keep the folder name stable on each machine, or symlink to your local skill id.
3. Open `SKILL.md` — frontmatter `name` / `description` decide when agents load it.

Local source id (this box): `tvp`
