# TVP 自媒体发布文案（每条成片必交）

成片交付时**必须**同交 `PUBLISH.md`（工程根目录），内含可直接粘贴的多平台介绍，方便发抖音 / 视频号 / 小红书 / B 站等。事实以 `SOURCES.md` 为准，禁止编造规格。

## 必交三段（同一选题三变体）

| 代号 | 名称 | 用途 | 长度感 |
| --- | --- | --- | --- |
| **A** | 主推版 | 默认首发、长描述栏 | 钩子一句 + 管道/价值 3–6 句 + 网友/对照一句 + CTA 问句 + `#标签` |
| **B** | 一句话短版 | 字数紧的平台、转发二次粘贴 | 2–4 短句打穿卖点 + `#标签` |
| **C** | 结构化要点版 | 偏硬核/清单读者 | 标题行 + `▪️` 要点 4–6 条 + 收束一句 + `#标签` |

## 写法铁律

1. **口语、好扫**：像口播补文案，不用内部黑话（短收束、可外推、证据边界等）。
2. **钩子先行**：A/B 第一句必须是结果或反差（「一句话让真机器人后空翻」），不要先堆项目名说明书。
   - **例外 · 可搜品牌+型号（Justin 2026-11-05 SEO/流量）**：若选题有大众可搜的产品名（如「腾讯混元Hy4」），**A 开场 / B 一句话 / C 标题行先写品牌+型号，再接钩子**（`腾讯混元Hy4：第一次能看图、还能点电脑`）。这是流量关键词前置，不是说明书堆砌；能力钩子仍要跟紧。标签保留 `#混元` `#Hy4` 等专名。
3. **管道说人话**：技术链写成「输入 → 中间步 → 机器人能干什么」，必要时再给英文专名。
4. **数字可核**：DOF、机型、定价、论文数字必须出自 `SOURCES.md`；不确定就删，不猜。
5. **标签收尾**：每段末尾一组 `#`，含选题专名 + `科技快播` / `科技新闻` 等通用标；专名标签优先。
6. **能力边界诚实**：非商用、科研-only、演示≠量产等写进 A 或 C 一句即可，勿吓人恐吓。
7. **交付形态**：`PUBLISH.md` 用三级标题分 A/B/C；每段一整块纯文本，方便手机长按复制。成片聊天气泡里**顺带贴出三段**（或先贴 A，注明 B/C 在 `PUBLISH.md`）。

## 金标范例：Video2Robot（用户标定）

见工程 `video2robot_oss/PUBLISH.md`。结构摘要：

- **A 主推**：钩子「一句话让真机器人后空翻」→ 管道白话 → 机型/门槛 → 网友辣评 + 对照新闻 → CTA + 标签
- **B 短版**：三句打穿「文字→姿态→关节指令」+ 动捕时代对照
- **C 要点**：`📊` 标题 + `▪️` 管道/机型/输出/入口/门槛 + 收束「从编动作到说动作」

新选题仿此三变体，换事实与钩子，勿整段复读 Video2Robot。
